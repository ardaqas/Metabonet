# Decision log

D1–D9 come from `research_plan.md` §15 and are copied here so the log is in one place. Every later decision has a date and a reason. None of D10–D16 used any modelling results; no model has been fitted.

| # | Date | Decision | Reason |
|---|---|---|---|
| D1 | 2026-11-16 | Polar metabolites only | Mapping reliability; lipid GPR instability |
| D2 | 2026-11-16 | Solid-tumour lines as primary population | Removes adherent/suspension axis; comparable with Li 2022 |
| D3 | 2026-11-16 | First-neighbour gene sets, transporters included, union of GPR genes | Simplest biologically grounded definition |
| D4 | 2026-11-16 | Target gene-set size 3–60 | Excludes degenerate and hub targets without using outcomes |
| D5 | 2026-11-16 | Ridge with two-stage covariate adjustment | Stable, conservative, interpretable |
| D6 | 2026-11-16 | Random metabolic genes (N-met) as primary null | Separates network locality from general metabolic-gene information |
| D7 | 2026-11-16 | Pin Human-GEM v2.0.0 (commit hash recorded at download) | Most curated release; version drift affects gene sets |
| D8 | 2026-11-16 | CCLE 2019 RNA-seq (RSEM TPM) as expression source | Same release/namespace as metabolomics (alternative: current DepMap release) |
| D9 | 2026-11-16 | No FBA, no multi-omics, no external datasets, no flexible ML in core scope | Keep the project finishable and the question clean |
| D10 | 2026-11-16 | CCLE 2019 files are downloaded from the Broad CCLE server (`data.broadinstitute.org/ccle`). `Model.csv` = **DepMap Public 26Q3**, downloaded manually by the project owner. The release is taken from the README header and checked against the Model.csv schema (added 2026-11-16). | depmap.org is behind a Cloudflare Turnstile check and asks not to be scraped. The Broad server hosts the identical release files. The owner chose a manual current download over the older but scriptable figshare 24Q4. |
| D11 | 2026-11-16 | Primary set: **solid tumour** = current `OncotreeLineage` ∉ {Lymphoid, Myeloid}, and not non-cancerous (`OncotreePrimaryDisease == "Non-Cancerous"` or lineage Fibroblast). Solid lines that grow in suspension or mixed culture (44 + 55) are **kept and flagged** (`growth_pattern`). | Puts research_plan §4 step 6 into practice ("flag growth type"). Lineage-based definition as in D2. Fibroblast lines are not tumours. Adherent-only count (633) is reported for comparison with Li 2022. |
| D12 | 2026-11-16 | Medium is assigned from Li et al. 2019 Supp. Table 1, falling back to the 2019 `Growth.Medium`. Strings are normalised by ordered component regexes (`src/phase0/medium.py`). DMEM + Ham's F12 counts as **DMEM:F12**. Any other combination of two or more base media is a **mixture**. Strings offering alternatives ("X or Y") are **ambiguous** and left unassigned. Alpha-MEM, F12K, F10 and F12 are kept as their own base media, separate from EMEM/MEM and DMEM:F12. Serum % is parsed for information only and not used. | Follows research_plan §4 step 5. The formulations differ, so they aren't merged by name similarity. Mixtures have no single base medium. |
| D13 | 2026-11-16 | Base media and mixtures with < 15 lines in the primary set become **`other`**. Mixtures always go to `other`. Medium coverage counts every assigned category, `other` included, and excludes only unknown or ambiguous. Model.csv `FormulationID` is **not** used. | Follows the plan's collapsing rule. "Other" is a known medium, just a rare one. The plan names two medium sources, and adding a third would expand scope. |
| D14 | 2026-11-16 | **Donor groups** are connected components over: same DepMap `PatientID`; same RRID; Cellosaurus `OI` (same individual); Cellosaurus `HI` (derived from); and Cellosaurus "problematic: shown to be a X derivative". Grouped CV must keep each `donor_group_id` within one fold. | research_plan §8 (grouped splitting) and §10.3 (no same-donor leakage). |
| D15 | 2026-11-16 | Lines that Cellosaurus marks problematic (misclassified or contaminated) are **kept and flagged** (`is_problematic`, 26 lines in the primary set). Their lineage comes from current DepMap, which already reflects most reclassifications. If a contaminant line is also in the set, the two share a donor group. | Both omics layers were measured on the same physical stocks, so the expression–metabolite pairing stays valid. Lineage is corrected upstream, and same-donor leakage is handled by D14. Dropping 26 lines would only shrink n. |
| D16 | 2026-11-16 | **Duplicate cell line:** when current DepMap has merged a line's ID into another ModelID that is also in the metabolomics set, the merged line is excluded and the canonical line kept. This applies only to **HCC1588_LUNG**: ACH-001078 is now an alias of ACH-000007 = LS513_LARGE_INTESTINE. | Two metabolomics profiles of one cell line would count it twice. Keeping the canonical ModelID is a rule that doesn't look at outcomes. |
| D17 | 2026-11-16 | Lineage categories with < 15 primary-set lines collapse to **`Other`**: Soft Tissue 10, Thyroid 10, Pleura 9, Prostate 7, Biliary Tract 6, Ampulla of Vater 2, Cervix 1, giving 45 lines. | research_plan §4 step 4. |
| D18 | 2026-11-16 | **Missingness rule:** a metabolite is a target only if ≤ 20 % of its primary-set values were missing before MICE imputation. This removes 21 of 136 polar metabolites (115 remain eligible on this rule) and no positive control. | Above 20 %, a fifth or more of the values are imputed guesses that borrow information from other lines. Set before any mapping or modelling. |
| D19 | 2026-11-16 | **Batch-covariate sensitivity analysis dropped.** It is recorded as a limitation and as a deviation in `expectations.md` §8. | The four LC-MS batch labels are in none of the sources (Phase 0 audit). Does not affect the primary analysis. |
| D20 | 2026-11-16 | **Fourth sensitivity analysis:** primary set without the 26 Cellosaurus-problematic lines (n = 709). The sensitivity limit is raised from three to four. | Reviewers are likely to ask about it. The three-analysis cap guards against choices made after seeing results, and none exist yet.
